# OfficeCare - Office Issue & Complaint Tracker

OfficeCare is a simple web-based application for managing office complaints and issues.

I created this project to solve a common problem in offices where employees report problems through WhatsApp, calls, emails or verbally, and sometimes the issue gets missed or forgotten.

With OfficeCare, issues can be reported and tracked from one place.

## What OfficeCare Can Do

- Report a new office issue
- Add employee name and department
- Select issue category
- Set issue priority
- Assign issue to a team
- Track issue status
- Search issues
- Filter issues
- View complete issue details
- Mark issues as resolved or closed
- Detect overdue issues
- Calculate resolution time
- Show dashboard statistics
- Show basic analytics
- Save data in browser localStorage
- Responsive design for mobile and desktop

## Issue Status

An issue can have these statuses:

- Open
- In Progress
- Resolved
- Closed

## Priority

The application supports four priority levels:

- Critical
- High
- Medium
- Low

## Issue Categories

Some of the categories included are:

- IT and Software
- Internet and Network
- Printer
- AC and HVAC
- Electrical
- Plumbing
- Furniture
- Housekeeping
- Security
- Other

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Git and GitHub

No backend or database is required for the current version.

## How to Run

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in a browser.

Or use VS Code with the Live Server extension.
